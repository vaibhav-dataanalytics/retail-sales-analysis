Retail Sales Analysis using Python

Project Overview

This project focuses on analyzing retail sales data using Python to understand sales performance, revenue distribution, and business trends.

The project includes data cleaning, exploratory data analysis (EDA), and visualization to generate meaningful insights from retail sales data.

Objectives

- Analyze retail sales data.
- Clean and prepare the dataset for analysis.
- Understand category-wise sales performance.
- Analyze revenue by city.
- Explore monthly sales trends.
- Compare online and store sales.
- Identify product revenue patterns.
- Visualize sales and revenue distribution.

Tools & Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

Analysis Performed

1. Data Cleaning

- Prepared the dataset for analysis.
- Created a cleaned dataset for further exploration.

2. Category-wise Sales Analysis

Analyzed sales across different product categories to understand category performance.

3. City-wise Revenue Analysis

Explored revenue generated across different cities.

4. Monthly Sales Analysis

Visualized monthly sales trends to understand changes in sales over time.

5. Online vs Store Sales

Compared sales performance between online and physical store channels.

6. Product Revenue Analysis

Analyzed revenue generated by different products.

7. Revenue Distribution

Visualized the distribution of revenue across the dataset.

How to Run the Project

1. Clone or download this repository.
2. Install the required libraries:

pip install pandas matplotlib jupyter

3. Open Jupyter Notebook:

jupyter notebook

4. Open "RETAIL_SALES_ANALYSIS.ipynb".
5. Run the notebook cells to explore the analysis.

Conclusion

This project demonstrates the use of Python for retail sales data cleaning, exploratory data analysis, and visualization.
